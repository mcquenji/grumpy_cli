## 0.1.0

- Build CLI applications with command modules, typed arguments, and injectable prompts.
- Generate immutable AppConfig snapshots, setting handles, JSON schemas, and settings references from annotated global/local models through grumpy_gen.
- Allow local files to override every global setting, with explicit scoped writes and provenance.
- Use grumpy_io filesystem contracts and safe file replacement for configuration.
- Reuse core module lifecycle and awaited application shutdown.
- Replace runtime behavior through Grumpy service and datasource builders.
- Enforce package structure, DI conventions, and public documentation with grumpy_lints and analyzer checks.
- Include a consuming application with generated config, guided setup, and an in-memory filesystem alternative.
